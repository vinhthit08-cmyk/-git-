**1. 今日重点**

1. 数字化美育资源征集进入暑期报送窗口  
来源与日期：辽宁师范大学教务处，2026年7月24日。通知提出征集“艺术技能资源、艺术活动资源、智能化应用案例”三类数字化美育资源，服务国家智慧教育平台美育资源供给；同时明确不得侵犯知识产权、不得违规采集个人敏感信息、不得含商业广告。对一线教师的启发是：下学期的精品课、社团活动、AI辅助美术案例，要从一开始就按“可共享资源”标准留存教学设计、视频片段、评价证据和版权说明。([jwc.lnnu.edu.cn](https://jwc.lnnu.edu.cn/info/1025/4105.htm))

2. “一体化美育浸润体系”案例强调本土文化资源进课堂  
来源与日期：《中国教育报》，2026年7月28日。贺州学院设计学院案例以“课堂筑基、文化熏染、实践赋能”为主线，将瑶族服饰、地方建筑、民族文物、传统纹样数字化采集、文创开发等纳入课程与场馆学习。虽是高校案例，但对中小学美术教师的可迁移价值很强：把地方文化资源从“图片素材”升级为“观察、分析、转译、创作、展示”的学习链。([paper.jyb.cn](https://paper.jyb.cn/zgjyb/h5/html5/2026-07/28/content_144743_19739772.htm?utm_source=openai))

3. 国家智慧教育平台深化应用，教师备课资源与AI场景会继续扩容  
来源与日期：教育部，2026年7月18日。教育部召开国家智慧教育平台全面深化应用试点推进会，强调要认识人工智能带来的机遇和挑战，围绕资源供给、机制创新和师生一线应用需求提升平台效果。对美术教师来说，重点不是“平台上有什么课就照搬”，而是把平台资源用于导入、比较鉴赏、分层任务和课后拓展。([moe.gov.cn](https://www.moe.gov.cn/jyb_zzjg/huodong/202607/t20260718_1444258.html?utm_source=openai))

4. 学科美育改革的工作重点仍是“课堂提质、教师素养、数智赋能、质量评价”  
来源与日期：《中国教育报》，2026年5月27日。教育部学科美育教学改革现场推进会要求试点单位完善组织体系、提升教师美育素养、丰富教学特色资源、推进数智技术赋能、构建质量评价体系并加强动态监测。虽早于近 7 天，但它是下学期教研组制定计划的重要依据。([paper.jyb.cn](https://paper.jyb.cn/ZGJYB/html/2026-05/27/content_144742_19567324.htm))

5. “高雅艺术进校园”继续强调导讲、讲堂、沙龙和体验课  
来源与日期：教育部，2026年7月7日。三部门部署 2026 年高雅艺术进校园活动，安排艺术院团和高校演出，并要求结合艺术讲堂、作品导讲、艺术沙龙、艺术体验课等。美术教师可借鉴其“先导赏、再体验、再表达”的流程，用于美术馆看展、校园艺术节、戏剧美术/舞台视觉跨学科项目。([moe.gov.cn](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202606/t20260617_1440988.html?utm_source=openai))

**2. 可带进课堂的教学灵感**

1. “深度自然：一个问题生成一件作品”  
适用年级：小学中高段、初中。  
材料：树叶、树皮纹理照片、废纸板、透明片、麻绳、旧包装、丙烯/水彩、胶枪或白乳胶。  
时长：1-2课时。  
教学目标：训练学生从“自然是什么”提出问题，再用综合材料表达观点；对应广东美术馆儿童公共艺术季“深度自然”中以开放提问引导儿童创作的思路。课堂可让学生先写一个问题，如“手机屏幕和树皮，哪个更自然？”再完成一件材料拼贴或小装置。([gdmoa.org](https://www.gdmoa.org/Exhibition/Current/202606/t20260629_18369.shtml))

2. “家乡纹样数字档案与文创转译”  
适用年级：初中、高中，美术社团。  
材料：本地建筑、服饰、器物、窗棂、非遗图案照片；方格纸、硫酸纸、马克笔、平板/电脑可选。  
时长：3-4课时或项目化学习半天。  
教学目标：从本土图像采集到纹样提炼、色彩分析、现代应用设计，完成书签、徽章、海报或校园导视小样。可借鉴贺州案例中的“传统纹样现代设计转译”“纹样数字化采集”和“文创衍生品开发”路径。([paper.jyb.cn](https://paper.jyb.cn/zgjyb/h5/html5/2026-07/28/content_144743_19739772.htm?utm_source=openai))

3. “未来设计师装备：AI只做灵感板，学生完成设计判断”  
适用年级：小学二至五年级、初中低年级。  
材料：A4纸、彩笔、剪贴材料；教师可准备经筛选的AI生成参考图或手绘示意图。  
时长：1课时。  
教学目标：学习“功能-造型-色彩-使用者”的设计关系。教师可让AI辅助生成不同功能装备的灵感图，但学生必须说明：我的装备解决什么问题？哪些部分来自观察？哪些部分是我改造的？贵州教育报实践文章提到 AI 可用于素材生成、动态演示、过程追踪与评价，但课堂中应保留学生的构思草图和修改证据。([ictdedu.cn](https://www.ictdedu.cn/news/gddt/xxhdt/n20260625_89722.shtml?utm_source=openai))

**4. AI与数字艺术教育动态**

1. 《“人工智能+教育”行动计划》对美术教师的直接影响  
来源与日期：教育部等五部门，2026年4月2日印发、4月10日发布。文件提出鼓励人工智能跨学科教学，提升教师智能素养；在教师教学方面支持课前备课、学情分析、多模态资源生成、方案优化和个性评价反馈。对美术课堂的落点是：AI可辅助备课、生成参考、组织评价，但不能替代学生观察、手作、解释和反思。([hudong.moe.gov.cn](https://hudong.moe.gov.cn/srcsite/A16/s3342/202604/t20260410_1433240.html))

2. AI进课堂的边界更明确：安全、可信、可控  
同一行动计划强调要筑牢安全屏障，防范学术造假、应试内卷、隐私泄露等问题。美术教师今天就可以建立班级规则：学生使用AI图像或文字时必须标注工具、用途、修改过程；不得上传学生姓名、照片、家庭信息、成绩表；不得把AI生成图直接当原创作品提交。([hudong.moe.gov.cn](https://hudong.moe.gov.cn/srcsite/A16/s3342/202604/t20260410_1433240.html))

**5. 一线教师今天可执行清单**

1. 选一个下学期单元，把“最终作品评价”改成“草图、材料实验、同伴反馈、修改说明、成品展示”五格过程档案。  
2. 从本地建筑、非遗、社区景观或校内植物中拍 10 张图，建立一个“本土美术素材夹”，每张图附一句可提问的话。  
3. 试写一个 AI 使用声明模板：用了什么工具、用于哪个环节、哪些内容由学生独立完成。  
4. 为一节课准备 3 个开放问题，替代单纯示范步骤，例如“这个材料最想表达什么？”“如果换一种观看距离，作品会变吗？”  
5. 教研组可用 20 分钟共读一篇案例，讨论“这节课的真实问题、核心任务、评价证据分别是什么”。

**7. 最新论文观点与可借鉴写作模式**

1. 观点一：对话型鉴赏不仅培养学生，也能改变教师的观看方式。  
2026年7月8日公开的日本《美术教育学》论文《对话型鉴赏を通じた教師の思考変容に関する一考察》以教师研修中的立体作品审查与对话型鉴赏为案例，指出教师在讨论儿童作品时，会通过想象创作过程、理解儿童意图、接纳他者视角来反思自身课堂。可借鉴到校本教研：不要只评“好作品”，要让教师围绕“学生为什么这样做”开展证据式讨论。([jstage.jst.go.jp](https://www.jstage.jst.go.jp/browse/aaej/47/0/_contents/-char/ja))

2. 观点二：小学美术跨学科主题学习要从“主题统领、真实情境、学习任务、学段评价”入手。  
周权《素养导向下小学美术跨学科主题学习的实施策略》提出，以美术视觉转译为核心，创设真实情境，推动多学科融通，设置学习支架，并形成学段差异化评价。适合一线教师写“课例型论文”：先写课程改革背景，再写学校/班级真实问题，随后呈现任务链和评价表。([zsyyb.cn](https://zsyyb.cn/abs/202602.01919?utm_source=openai))

3. 观点三：初中美术跨学科主题学习的难点在评价机制、师资培训和融合模式。  
刘榴硕士论文《跨学科主题学习在初中美术课程中的教学实践研究》通过问卷、访谈、观察等方法，构建初中美术跨学科主题学习流程并分析实践效果；其提醒是，跨学科不是把多个学科元素拼在一张课件里，而是要有共同问题、共同产出和可观察的能力变化。([cnki.istiz.org.cn](https://cnki.istiz.org.cn/kcms/detail/detail.aspx?dbcode=CMFD&dbname=CMFD2026&filename=1025564405.nh&utm_source=openai))

4. 观点四：中华优秀传统文化融入小学美术，适合写成“地方文化资源转译”论文。  
人大复印资料收录的《中华优秀传统文化融入小学美术跨学科主题学习的设计与实施——以“探寻江夏堂之美”为例》强调凝练文化价值、重组学习内容、突出审美体验，并以“以美立德、以美启智、以美润心、以美化人”组织实施路径。教师可仿写本地祠堂、老街、桥梁、剪纸、木版年画、少数民族纹样等案例。([rdfybk.com](https://www.rdfybk.com/qw/detail?id=916330&utm_source=openai))

推荐文章模式：

1. “政策背景 + 课堂痛点 + 真实问题 + 项目任务链 + 过程性评价 + 反思改进”  
适合写跨学科、项目化学习、美育浸润论文。

2. “地方资源考察 + 图像/纹样分析 + 教材单元对接 + 学生创作转译 + 校园展示/社区传播”  
适合写非遗、地方文化、馆校合作、美术校本课程论文。

3. “AI工具场景 + 教师审核机制 + 学生创作过程证据 + 诚信声明 + 作品评价变化”  
适合写 AI 赋能美术课堂，但必须把论文重点放在教学设计和学生学习证据上，而不是介绍工具功能。

4. “一次教研活动 + 儿童作品证据 + 教师对话记录 + 观念变化 + 下一轮课堂调整”  
适合写美术教研论文，尤其适合围绕作品评价、对话型鉴赏、教师专业成长展开。

**5. 一线教师今天可执行清单**

1. 选一个下周要上的课，补写“评价证据”：学生最后交什么作品、过程留下什么草图/口头说明/同伴评价。
2. 把一个传统文化内容改成“图像识读问题链”：看见什么、怎么表现、为什么这样表现、我能如何转化。
3. 建一个班级作品过程文件夹，按“草稿、修改、成品、反思”四类保存，不只保存优秀成品。
4. 用本地资源备一张“地方美育素材卡”：地点、非遗/展览/建筑/民俗、可对应年级、可用材料、1个创作任务。
5. 若使用AI备课，今天只让AI生成“问题清单和评价量规初稿”，教师再人工删改，避免照搬。

**6. 风险与提醒**

1. 近7天内可公开检索到的国内中小学美术教育政策/教研新增不足，本晨报已用近一两个月仍重要的政策和案例补足。
2. 艺术素质测评高度依赖地区政策，无锡、南京、常州等地做法不能直接等同于全国统一要求，教师应以本省市教育局文件为准。
3. 美术馆、博物馆、公教活动的时间、预约、收费、适龄要求可能变动，带学生参与前需二次核验馆方官网或公众号。
4. AI用于学生作品评价时要谨慎：不上传学生人脸、姓名、学籍号、家庭信息；不把AI评分作为唯一评价；不让AI替代教师的人文判断。
5. 课堂使用网络图片、艺术家作品、展览图像时，应注明来源；学生公开展示作品涉及肖像、声音、视频时要取得必要授权。

**推荐的一线教师论文写作模式**

1. **问题诊断型**：课堂现状问题 → 成因分析 → 策略设计 → 课例验证 → 反思改进。适合写“教学评一体化”“公开课表演化纠偏”“大单元教学困境”。
2. **课例行动研究型**：学情与目标 → 任务链设计 → 课堂实施片段 → 学生作品证据 → 评价与二次改进。最适合一线教师投稿。
3. **资源转化型**：地方文化/美术馆/非遗资源 → 课程价值分析 → 学段适配 → 活动设计 → 学习成果展示。适合写校本课程和项目化学习。
4. **技术赋能型**：教学痛点 → AI/数字工具介入点 → 人机分工 → 学生安全与版权边界 → 效果评估。注意必须写“教师如何把关”。
5. **评价改进型**：原评价问题 → 核心素养指标 → 过程性证据采集 → 量规/档案袋 → 反馈促进学习。适合对接艺术素质测评和日常课堂评价。

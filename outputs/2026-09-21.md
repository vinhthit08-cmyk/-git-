## 2. 可带进课堂的教学灵感

### 灵感一：传统纹样的“再设计”工作坊

- **适用年级：**小学四至六年级  
- **课堂时长：**2课时，每课时40分钟左右  
- **材料：**彩纸、马克笔、水彩笔、剪刀、胶棒、方格纸；可选用博物馆公开展品图片  
- **活动流程：**
  1. 观察一件传统服饰或工艺品，圈出重复纹样、主色和对称关系。
  2. 将传统纹样拆成“基本形—重复方式—色彩关系”。
  3. 设计一个服务于校园生活的现代纹样，如校本课程封面、书签、班级旗帜或文具包装。
  4. 为作品写一段50字以内的“来源说明”和“改造说明”。
- **教学目标：**理解纹样的形式规律和文化语境；训练概括、重复、对称和色彩组织能力；建立“借鉴而不照搬”的版权与文化尊重意识。
- **评价重点：**是否说明来源；形式变化是否清晰；纹样是否适合具体使用场景；是否能解释自己的设计选择。

### 灵感二：“诗意栖居”校园空间观察项目

可结合中国国家博物馆当前展览信息中的“诗意栖居”主题。[中国国家博物馆展览预告](https://www.chnmuseum.cn/zl/zhanlanyugao/)

- **适用年级：**初中七至八年级  
- **课堂时长：**2课时，也可拓展为一周小项目  
- **材料：**A3纸、铅笔、墨水、水彩或彩铅；手机拍摄仅用于记录校园空间，须遵守学校管理规定  
- **活动流程：**
  1. 选择校园中的一个角落：窗边、楼梯、树下、走廊或操场边。
  2. 分别用“俯视、平视、局部特写”三种视角观察。
  3. 选择一种中国传统绘画或现代设计的空间组织方式完成作品。
  4. 在作品背面写出“这个空间如何影响人的情绪和行为”。
- **教学目标：**理解空间、视点、构图和环境氛围；从“画景物”进入“表达人与环境关系”；建立美术与校园生活、生态观察的联系。
- **评价重点：**观察是否具体；视角是否有意识；空间关系是否清楚；作品是否表达了个人体验而非简单复制范画。

### 灵感三：“手绘与AI谁更懂主题”视觉判断实验

可结合教育部关于“人工智能+教育”的政策方向，但必须使用学校允许的工具和账号环境。

- **适用年级：**高中一至二年级  
- **课堂时长：**2至3课时  
- **材料：**素描纸、马克笔或水彩、学校批准的AI图像工具、过程记录表  
- **活动流程：**
  1. 统一主题，例如“未来的社区”“我的家乡记忆”或“人与自然”。
  2. 学生先完成一张手绘草图，写下构图和视觉意图。
  3. 在不上传个人照片、姓名、声音和同学作品的前提下，使用AI生成一至两张参考图。
  4. 对比手绘和AI图像：构图、细节、情绪、文化准确性、材料质感、作者意图。
  5. 最终完成一张人工修改或综合创作，并提交提示词、草图、修改记录和反思。
- **教学目标：**培养图像判断、视觉表达、媒介选择和数字伦理意识；理解AI可以辅助构思，但不能替代观察、判断、修改和责任承担。
- **评价重点：**过程证据、主题理解、修改质量和反思深度，不以“AI生成图像是否漂亮”作为主要标准。

- AI可以用于资料整理、构思发散、图像对比、展览信息检索和形成性评价辅助。

## 5. 最新美术教育论文：观点与借鉴

### 近期观点

1. **生成式AI改变的是教师的工作结构，而不只是增加一个工具。**  
   《美术教育研究》2026年相关论文讨论了生成式AI背景下美育工作者角色的变化，强调教师需要成为需求分析者、资源筛选者、学习过程设计者和价值判断者，而不是单纯的“提示词操作者”。  
   参考：[《美术教育研究》2026年第4期相关论文条目](https://www.chinajournalpub.com/14/2026/4/5/139.html)

2. **AI绘画进入中小学课堂后，最大的风险之一是学生的具身经验被削弱。**  
   《具身认知视域下AI绘画介入中小学美术教育的风险及对策》强调，绘画中的观察、触摸、材料阻力、手部动作和持续修改本身就是学习内容。AI可以辅助构思，但不应替代真实观察、手工操作和视觉判断。  
   参考：[《具身认知视域下AI绘画介入中小学美术教育的风险及对策》](https://ojs.vitu-pub.com/index.php/jie/article/view/7486)

3. **跨学科融合必须有美术学科核心任务，不能只是把其他学科内容拼接进来。**  
   《核心素养视域下小学美术跨学科融合教学路径探索》强调以主题或真实问题组织学习，但最终仍要落实到造型表现、设计应用、欣赏评述、综合探索等美术学科能力。  
   参考：[《核心素养视域下小学美术跨学科融合教学路径探索》](https://www.cfxybk.com/journal.php/item-detail/1921)

4. **地域文化资源要经过课程化处理，不能停留在“介绍地方文化”。**  
   《美育浸润视域下地域文化与中学美术教学融合路径研究》提示，地方文化进入课堂时，需要经过资源筛选、视觉分析、任务转化、创作实践和评价反思，才能形成真正的课程内容。  
   参考：[《美育浸润视域下地域文化与中学美术教学融合路径研究》](https://lntcxb.ccla.com.cn/CN/10.13896/j.cnki.wty.2026.04.013)

### 可借鉴的论文写作模式

**模式一：课例行动研究型**

适合写一节课或一个单元：

> 教学问题 → 学情诊断 → 任务设计 → 教学实施 → 学生作品与过程证据 → 评价结果 → 教师反思

关键是保留证据，例如学生前后作品、课堂观察记录、学习单、访谈、评价量规，而不只是描述活动流程。

**模式二：地方文化资源课程化型**

适合写非遗、博物馆资源、地方艺术：

> 资源来源 → 视觉与文化特征分析 → 课程目标 → 学习任务 → 创作转化 → 文化理解与版权边界 → 学习评价

文章中要回答三个问题：为什么选这个资源？它如何转化为美术学习任务？学生学到了什么可以被观察和评价的能力？

**模式三：AI介入课堂的比较研究型**

适合写AI美术教学：

> 明确教学问题 → 设置人工创作/AI辅助/综合创作任务 → 保留全过程材料 → 比较作品与学习行为 → 分析优势与风险 → 提出使用边界

建议避免只比较“谁生成的图更好看”，应比较观察质量、构图决策、修改次数、主题理解、文化准确性、原创说明和反思能力。

## 6. 一线教师今天可执行的5项行动

1. **选一节本周课程，补上过程性评价表。** 至少记录草图、尝试、修改、最终作品和一句自我反思。  
2. **从一个博物馆或非遗资源中挑选一件作品，设计一个20分钟“观察—提问—转化”任务。** 不要只安排图片欣赏。  
3. **检查一个教学单元是否只有“做作品”，没有明确的驱动问题。** 将任务改写为“为谁解决什么视觉问题”。  
4. **如学校允许使用AI，先制定课堂规则。** 明确哪些资料不能上传、如何标注AI参与、如何提交草图和修改记录。  
5. **建立一个精品课或校本教研资料夹。** 内容包括教学目标、课件、学生过程照片、典型作品、评价表和课后反思，便于后续教研与公开课使用。

## 7. 风险与提醒

- **地方项目不等于全国政策。** 上海美育评价项目、广州馆校合作、浦东AI研修均具有地方实践属性，不能直接当作全国统一要求。
- **注意事件日期与报道日期。** 本期部分新闻的活动发生在9月10日或9月14日，但报道发布时间在近7天内，已分别标注。
- **展览和活动安排可能变化。** 现场参观、报名、展期和教育活动时间应以博物馆官网最新公告为准。
- **版权边界要提前说明。** 展览图片、教材页面、学生作品和网络图像用于课堂展示时应注明来源；不应未经授权上传到公开平台或用于商业传播。
- **学生隐私不能进入公共AI工具。** 不上传学生姓名、脸部照片、声音、联系方式、家庭信息、未公开作品或可识别的课堂视频。
- **AI作品必须保留过程。** 建议提交草图、提示词、生成结果、修改记录和反思；不能把未经说明的AI生成图直接作为学生个人原创成果。
- **论文属于学术观点，不是操作规范。** 使用论文观点时应结合本校学段、班级基础和学校管理制度，不宜直接照搬结论。

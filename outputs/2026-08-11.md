**1. 今日重点**

1. **AI进美术课堂：更强调“辅助”而不是“替代”**
来源与日期：央广网转载《中国教育报》，2026-07-27。文章提醒，AI绘画、虚拟仿真可缓解资源不足、提高技法训练效率，但美术课不能用AI图像替代真实观察、不能让学生直接生成草图后临摹成作业，也不能用AI鉴赏文本替代自主查阅、比较和讨论。对一线教师最有用的判断是：AI可以用于“启发、对比、反馈、延展”，但审美感知、创意实践、文化理解仍要由真实观察和人工表达支撑。([edu.cnr.cn](https://edu.cnr.cn/gc/20260727/t20260727_527731823.shtml))

2. **教师使用生成式AI已有明确边界，可直接转化为校本规范**
来源与日期：中国教育学会发布，来源为教育部教师队伍建设专家指导委员会，2025-11-28。指引将生成式AI应用分为学习、教学、育人、评价、管理、研究等场景；同时明确教师须审查AI生成内容，AI不得替代教师作最终评价，学生使用AI要标注工具和使用环节，小学生原则上不得独立使用生成式AI。美术教师今天可据此制定“美术作业AI使用声明”和“作品过程性材料提交要求”。([cse.edu.cn](https://www.cse.edu.cn/index/detail.html?category=148&id=4743)) ([cse.edu.cn](https://www.cse.edu.cn/index/detail.html?category=148&id=4743)) ([cse.edu.cn](https://www.cse.edu.cn/index/detail.html?category=148&id=4743))

3. **“人工智能+教育”行动计划正在影响美育数字化方向**
来源与日期：教育部等五部门，文件生成日期2026-04-08，发布页为2026年4月。该计划提出推动AI与教育全要素融合，强调中小学人工智能教育、跨学科教学、教育大模型安全审核、AI进校园管理和隐私风险防范。对美术教师的实际意义是：AI工具进入课堂要有课程目标、过程证据、内容审核和数据安全底线，不能只追求“出图快”。([moe.gov.cn](https://www.moe.gov.cn/srcsite/A16/s3342/202604/t20260410_1433240.html?utm_source=openai))

4. **学校美育浸润案例继续从“活动化”走向“课程化、场景化”**
来源与日期：《中国教育报》，2026-07-28，贺州学院设计学院案例。报道呈现“课堂筑基、文化熏染、实践赋能”的一体化美育浸润体系，把大学美育、美术鉴赏、书法鉴赏、生活美学、设计创意等模块整合，并把瑶族服饰、地方建筑、传统纹样、校园空间微更新、海报设计等转化为课程任务。中小学可借鉴其思路：不只是办展演，而是把本地文化资源做成稳定课例、作品任务和评价证据。([paper.jyb.cn](https://paper.jyb.cn/zgjyb/h5/html5/2026-07/28/content_144743_19739772.htm?utm_source=openai))

**2. 可带进课堂的教学灵感**

1. **真实观察 vs AI图像：一片叶子的两种视觉证据**
适用年级：小学高年级、初中。  
材料：真实树叶、放大镜或手机微距、铅笔/彩铅/水彩、可选AI图像工具教师端演示。  
课堂时长：1课时，40-45分钟。  
教学目标：训练审美感知和细节观察；理解AI图像“完美但可能不真实”的特点；建立“观察记录、手绘表达、AI对比、反思说明”的创作流程。  
做法：先画真实叶脉、破损、色差和边缘，再看AI生成叶片，讨论“哪些细节可信，哪些细节像模板”。最后让学生写一句创作声明：我的观察来自哪里，AI只在哪一步提供参考。

2. **地方非遗纹样的现代转译**
适用年级：初中、高中、社团或项目化学习。  
材料：本地非遗纹样图片、校史/地方文化资料、拷贝纸、剪纸或版画材料、马克笔、电脑绘图软件可选。  
课堂时长：2-3课时或社团项目。  
教学目标：理解传统纹样的造型、色彩和寓意；学习“采集、拆解、重组、应用”的设计方法；形成文化理解与创意实践证据。  
来源启发：韩山师范学院美术学院将潮绣、剪纸、潮塑、潮彩、手拉壶等地方非遗转化为课程、工作室、企业项目和数字设计任务，特别强调“双导师”和真实项目。中小学可缩小为“一个纹样、一件校园用品、一段设计说明”。([paper.jyb.cn](https://paper.jyb.cn/zgjyb/h5/html5/2026-07/13/content_144743_19697173.htm))

3. **水墨与AI时代：谁在决定一幅画的气息**
适用年级：初中高年级、高中美术鉴赏、数字艺术社团。  
材料：中国画作品图像、AI生成水墨图像示例、宣纸/水墨或水彩、作品比较表。  
课堂时长：1课时鉴赏加1课时创作。  
教学目标：比较笔墨、肌理、留白、气韵与算法生成图像的差异；理解技术媒介对艺术表达的影响；培养批判性视觉判断。  
来源启发：中国美术馆“我们+——张望水墨与AI时代”展期为2026-08-02至2026-08-12，可作为“水墨语言与AI生成图像”的讨论入口。([namoc.cn](https://www.namoc.cn/namoc/zhanlan/zl_list.shtml))

**4. AI与数字艺术教育动态**

1. **教师备课可用AI，但必须保留专业判断**
生成式AI可辅助教案、课件素材、作业设计、量规设计和教学反思；但教师要审核事实、价值导向、难度和适配性，不能把AI生成的评语或开放性作品评分作为最终评价。美术课堂尤其要防止“模板化评语”和“只看成品不看过程”。([cse.edu.cn](https://www.cse.edu.cn/index/detail.html?category=148&id=4743)) ([cse.edu.cn](https://www.cse.edu.cn/index/detail.html?category=148&id=4743))

2. **AI美术课堂的更稳妥流程：先人后机、先过程后效果**
近期美术教育讨论的共识是：先让学生观察、草图、材料实验、同伴讨论，再用AI做风格联想、构图备选或效果对比；最后要求学生提交过程照片、草图、修改说明和AI使用声明。这个流程能降低抄袭、代做、同质化和隐私风险。([edu.cnr.cn](https://edu.cnr.cn/gc/20260727/t20260727_527731823.shtml)) ([cse.edu.cn](https://www.cse.edu.cn/index/detail.html?category=148&id=4743))

**5. 一线教师今天可执行清单**

1. 给本周一节课加一个“过程性证据”要求：草图、观察记录、材料试验照、修改说明任选两项。  
2. 建一个“AI使用声明”小模板：工具名称、使用环节、生成内容是否进入最终作品、我修改了什么。  
3. 从中国美术馆或中央美院美术馆当前展览中选1件作品，做一张“看什么、怎么问、如何创作迁移”的备课卡。  
4. 找一个本地非遗或地方视觉资源，拆成“图案、色彩、材料、用途、寓意”五栏，准备下次教研分享。  
5. 设计一个4级美术评价量规：观察真实、形式表达、文化理解、创作反思，每项只写一句可观察标准。

**6. 风险与提醒**

1. **时效风险**：近7天内全国层面美术教育政策新发文较少，本报纳入了2026年4-7月仍在影响课堂的政策、报道和研究；展览结束日期请以馆方页面和预约系统为准。  
2. **地区适用性**：贺州、潮州等案例有明显地方文化条件，不能照搬资源名称，应转化为本校、本区县可获得的文化材料。  
3. **版权边界**：展览图像、画册、期刊图片不要直接打包上传到公开网盘或商业课件；课堂展示优先使用馆方公开页面、公共教育资源、自己拍摄且获准使用的图片。  
4. **学生隐私**：不要把学生姓名、照片、人脸、家庭信息、作品原图批量上传到不明AI平台；课堂音视频采集需按学校要求取得授权。([cse.edu.cn](https://www.cse.edu.cn/index/detail.html?category=148&id=4743))  
5. **AI作业边界**：不建议小学生独立使用生成式AI；初高中使用也要提交过程材料并标注AI使用环节，不得直接提交AI生成完整方案或完整作品。([cse.edu.cn](https://www.cse.edu.cn/index/detail.html?category=148&id=4743))

**7. 最新美术论文观点与可借鉴文章模式**

1. **AI赋能小学美术：从工具优势转向核心素养评价**
论文：陈斌《核心素养引领下AI技术在小学美术教学中的运用探索》，《中小学电教》2026年第13期，发布时间/出版时间2026-07-10。核心观点是：AI可用于可视化创作、资源整合和智能反馈，推动小学美术个性化、多元化教学，但落点应是核心素养，而不是工具展示。可借鉴模式：  
“核心素养要求 → AI可支持的教学环节 → 课堂路径 → 教师角色变化 → 评价与风险”。([zxdj.cbpt.cnki.net](https://zxdj.cbpt.cnki.net/portal/journal/portal/client/paper/b24f2cfe12b5aa73564d7237db026623))

2. **教学评一致性：美术课题论文可从KDU目标与表现性评价切入**
论文：林蔚然、林烨《教学评一致性理念下初中美术本土化研究》，2026-03-25。文章提出目标设计以核心素养为指导，可用KDU框架分层表述，评价重视多元主体和表现性评价，教学过程再依据目标与评价选择策略，并以《现代艺术与科技融合的魅力》为例展开。可借鉴模式：  
“理论来源 → 中国美术课堂转化 → 目标分层 → 表现性任务/量规 → 课例验证”。([ojs.shiharr.cn](https://ojs.shiharr.cn/index.php/yishu/article/view/1547))

3. **博物馆资源与美术核心素养：适合写馆校合作或校本资源论文**
论文：何浩《博物馆资源与核心素养导向下美术教育的内在逻辑与耦合路径》，在线发表于2026-04-28。核心观点是：博物馆资源与美术核心素养之间可形成“资源支撑素养生成，素养需求导向资源转化”的双向机制；现实问题包括资源碎片化、教学适配不足、馆校协同松散、评价缺失。可借鉴模式：  
“资源类型梳理 → 核心素养对应 → 现实困境 → 资源包开发 → 馆校协同 → 素养评价”。([fspjournal.vip](https://www.fspjournal.vip/journal/jcet/1/3/61?utm_source=openai))

4. **生成式AI与绘画基础教学：重点不是替代示范，而是增强直观理解**
论文：兰正焱《生成式人工智能对绘画基础教学模式的影响研究——基于教学直观性视角》，2026年。摘要显示，文章讨论生成式AI在形体理解、认知转化、课堂节奏优化中的价值，同时强调“技术为用、教学为本”。可借鉴模式：  
“传统绘画基础教学痛点 → AI直观化功能 → 具体教学环节 → 使用边界 → 教学效果反思”。([ojs.shiharr.com](https://ojs.shiharr.com/index.php/rwxk/article/view/1390?utm_source=openai))

5. **推荐给一线教师的论文写作结构**
最稳妥的文章模式是“问题驱动型课例研究”：  
题目可写成“核心素养导向下××资源融入初中美术××课的教学实践研究”。正文结构建议为：政策与课标依据、学情与教学痛点、资源选择理由、教学目标与评价量规、课堂实施过程、学生作品与过程证据分析、反思与改进。  
如果写AI方向，必须单列“伦理与边界”一节，说明AI只用于启发、资料整理、反馈或效果对比，并要求学生保留草图、修改记录和使用声明。

**二、可带进课堂的教学灵感**

1. **项目：会“说”温暖的影偶故事**  
   适用年级：小学高段至初中七年级。  
   来源启发：郑州市小学美术大单元展示课《会“说”温暖的AI皮影》。([zzedu.net.cn](https://www.zzedu.net.cn/zzjcjy/jytz/10/34457866.shtml))  
   材料：黑卡纸或牛皮纸、透明片、两脚钉、竹签、剪刀、美工刀、手电筒或投影灯、手机录音；如学校允许，可用AI辅助生成故事分镜或角色参考图，但最终造型须学生二次设计。  
   课堂时长：2-3课时，每课时40分钟；社团可拓展为4课时。  
   教学目标：认识皮影造型的镂空、侧身、夸张与关节结构；学习用视觉形象讲述“温暖、互助、家乡记忆”等主题；培养分镜构思、角色设计、合作表演与反思表达能力。  
   操作建议：第一课时看皮影图像与地方故事，设计人物；第二课时制作影偶并调试光影；第三课时小组表演，评价维度设为“造型特征、运动结构、故事表达、合作修订”。

2. **项目：我的家乡自然名片**  
   适用年级：小学三至六年级、初中“综合·探索”单元。  
   来源启发：中国美协少儿美术额济纳巡展把胡杨、边塞风光、历史遗存、航天家国情怀转化为少儿美术与研学资源。([caanet.org.cn](https://caanet.org.cn/newsdetail.mx?id=10409))  
   材料：水彩、水粉、油画棒、拼贴纸、地图打印件、照片资料、自然观察记录单。  
   课堂时长：2课时；如结合写生可做成半日研学或社团项目。  
   教学目标：引导学生观察本地自然景观与文化符号，学习用色彩、构图和文字标签完成一张“家乡自然名片”；理解美术与地理、语文、地方文化的关系。  
   操作建议：教师先给出“一个地貌/植物/建筑/非遗符号+一句说明+一种主色调”的任务框架；学生完成作品后用30秒讲述“我为什么选择它”。

3. **项目：一张版画如何连接美术馆和校园**  
   适用年级：小学高段、初中社团、高中选修或校本课程。  
   来源启发：上海中学“‘艺’起长大——美术馆奇妙日&版画进校园成果展”，展期2026年10月8日-11月6日，依托刘海粟美术馆等公共文化资源，把作品欣赏、版画体验、主题创作连接起来。([shs.cn](https://www.shs.cn/info/1571/113441.htm))  
   材料：吹塑纸、KT板或橡皮章材料，水性油墨或水粉，滚筒，宣纸/素描纸，铅笔，旧报纸。  
   课堂时长：2课时；社团可拓展为“校园小型版画展”。  
   教学目标：了解版画“刻、滚、印”的基本过程；体验复数性和肌理美；学习从场馆作品或校园生活中提炼图像主题。  
   操作建议：第一课时做“看图-拆线-制版”，第二课时印制与布展。评价时不只看印得是否干净，还看学生是否能说明“图像来源、版痕特点、修改过程”。

2. **中小学生使用生成式AI要先定规则，区分独立完成、合理辅助与人机协作任务**

   对美术教师的实际影响：今天就可以在作业说明里加一句“AI使用声明”。例如：允许用AI生成3个构图参考，但最终作品必须基于本人草图完成；提交时附“我使用AI做了什么、我修改了什么、哪些素材来自哪里”。  
   来源链接：中国教科院文章：([cnaes.edu.cn](https://www.cnaes.edu.cn/post/151812))

**五、一线教师今天可执行的行动建议**

1. **给正在上的一个单元补“表现性评价量规”**：至少设三项，建议为“主题理解、材料与技法、创意表达、过程修订、口头阐释”中选3项，每项分3级描述。

2. **把下一节技法课改成真实任务**：例如“学习剪纸”改为“为班级读书节设计一组剪纸窗花”；“学习色彩”改为“为校园一角设计秋季色彩方案”。

3. **设置AI使用边界**：在班级作业说明中明确“哪些环节可用AI、哪些必须独立完成、如何标注AI参与”。尤其避免学生直接提交AI图像当作本人作品。

4. **做一个本地资源清单**：今天先列出3个本地文化资源，如博物馆、美术馆、老街、非遗传承人、地方植物、桥梁、传统建筑；每个资源后面写一个可转化课题。

5. **收集一份学生过程证据**：本周美术作业不要只收成品，要求学生保留1张草图、1张修改图、1段50字创作说明，为美育评价和教研案例积累材料。

**六、风险与提醒**

1. **地区适用性**：郑州、芜湖、常州、上海、额济纳等信息多为地方或区域实践，不能直接等同于全国统一要求。可借鉴思路，但校内实施要服从本地教研安排和学校管理规范。

2. **近7天资讯不足的类别**：国家层面“美术学科专门政策”近7天公开信息有限，因此晨报补入了9月教材发行、2024年美育浸润行动、2026年期刊论文等相邻高价值内容。

3. **版权边界**：课堂使用美术馆、展览、艺术家作品图片时，应优先使用官方公开页面、教材授权资源、国家中小学智慧教育平台资源；公开发布学生作品或课例时，避免未经授权使用高清展览图、商业插画、影视剧照和AI生成的疑似侵权风格图。

4. **学生隐私**：发布课堂照片、展览视频、AI创作过程截图时，注意学生姓名、面部、学校、班级、家庭信息。未成年人作品公开展示建议取得学校和监护人同意。

5. **AI使用边界**：AI可辅助构思、资料整理、生成参考方案，但不能替代学生观察、草图、材料实验和表达反思。评价时要看学生的过程证据，不只看最终图像效果。

6. **未经确认事项**：部分搜索结果来自学校、地方教研平台或媒体转载，活动细节可能调整；需要参加活动或引用通知原文时，应以主办方官网最新页面为准。

**七、最新美术论文观点与可借鉴文章模式**

1. **跨学科融合论文的主流观点：美术要“融合”，但不能被其他学科稀释**  
   代表文献：汤徐怀《核心素养视域下小学美术跨学科融合教学路径探索》，《文教资料》2026年第9期。文章指出，小学美术有天然综合性，但实践中存在教师跨学科整合能力薄弱、美术本体地位边缘化、学生参与停留表层等问题，提出以课程统整能力、美术本体锚点、真实问题驱动来推进深度学习。([wjzz.cbpt.cnki.net](https://wjzz.cbpt.cnki.net/portal/journal/portal/client/paper/0fc66cfb1990730644bb9ccb4e7437f7))  
   可借鉴模式：  
   题目模式：`核心素养视域下 + 学段/内容 + 跨学科融合教学路径探索`。  
   文章结构：问题提出 → 概念界定 → 现实困境 → 实施路径 → 课堂案例或策略建议。  
   一线教师写作切入：不要泛泛写“美术+语文+科学”，而要说明主学科目标是什么、融合学科解决什么问题、学生作品如何证明素养发展。

2. **美育期刊近期关注“生命教育、生态艺术、现代媒体艺术、项目式学习”**  
   代表来源：《美育》2026年第4期目录。该期包含《联结与生成：小学美术跨学科融合中渗透生命教育的路径探索》《生态艺术跨学科学习在小学美术教学中的实践——走进麋鹿苑，共植生命之树》《高中现代媒体艺术跨学科教学的应用探索——以“我们的微电影”为例》等文章。([ncpssd.org](https://www.ncpssd.org/journal/details?gch=59687X&utm_source=openai))  
   可借鉴模式：  
   题目模式：`联结与生成/走进某地资源 + 某主题 + 小学/高中美术教学实践`。  
   文章结构：资源背景 → 育人价值 → 学习任务群 → 活动流程 → 学生作品分析 → 反思改进。  
   一线教师写作切入：可把“校园植物观察”“地方湿地”“城市老建筑”“校史馆”“劳动基地”转化为生态美育或生命教育主题。

3. **AI+美术论文的主流观点：AI适合进入PBL，但必须保留学生过程记录和教师评价责任**  
   代表文献：《AI大模型支持下的初中美术跨学科项目式学习设计与案例研究》，《现代教育进展》。摘要显示，文章聚焦AI大模型与初中美术跨学科PBL，提出设计框架并分析案例，强调真实问题解决与综合能力提升。([ojs.s-p.sg](https://ojs.s-p.sg/index.php/xdjyjz/article/view/31908?utm_source=openai))  
   可借鉴模式：  
   题目模式：`AI大模型支持下 + 初中/高中美术 + 跨学科项目式学习设计与案例研究`。  
   文章结构：技术背景 → 教学问题 → 设计框架 → 案例实施 → 效果分析 → 风险与对策。  
   一线教师写作切入：最好选择一个具体项目，如“AI辅助校园导视设计”“AI辅助传统纹样再设计”“AI辅助微电影分镜”，并呈现学生草图、提示词、修改稿、最终作品和反思。

4. **非遗与创客教育论文值得美术社团借鉴：从“了解非遗”走向“再设计、再造物、再传播”**  
   代表文献：硕士论文《基于创客教育的初中美术项目课程研究》，以赣傩面具为主题，设计“与傩对话、材料美学、IP设计、非遗造物、展示交流”等子项目。([cnki.istiz.org.cn](https://cnki.istiz.org.cn/kcms/detail/detail.aspx?dbcode=CMFD&dbname=CMFD2026&filename=1025518106.nh&utm_source=openai))  
   可借鉴模式：  
   题目模式：`基于创客教育/项目式学习的 + 初中美术 + 地方非遗项目课程研究`。  
   文章结构：地方资源分析 → 学情与教材对应 → 项目课程框架 → 子项目实施 → 成效与反思。  
   一线教师写作切入：选择本地剪纸、皮影、年画、陶艺、木版画、蓝印花布、民族纹样等资源，避免只做“资料介绍”，要设计学生能动手、能转化、能展示的任务链。

5. **博物馆/美术馆资源研究强调“资源转化”而非单次参观**  
   代表文献：《博物馆资源与核心素养导向下美术教育的内在逻辑与耦合路径》，2026年。摘要指出，博物馆资源与美术核心素养之间存在“资源支撑素养生成，素养需求导向资源转化”的双向机制，同时也有资源转化碎片化、教学适配不足、馆校协同松散、评价体系缺失等问题。([fspjournal.vip](https://www.fspjournal.vip/journal/jcet/1/3/61?utm_source=openai))  
   可借鉴模式：  
   题目模式：`博物馆/美术馆资源与核心素养导向下 + 美术教学 + 转化路径研究`。  
   文章结构：资源价值 → 当前问题 → 课程转化原则 → 课堂/场馆活动设计 → 评价与协同机制。  
   一线教师写作切入：写“参观前任务单、参观中观察单、参观后创作单、作品展评单”，比只描述“组织学生参观美术馆”更有研究含量。
